# 48条相关干扰轨迹：来源解释与实际计算采用审查

## 结论

已有48条的来源事件标注已逐条完成，未运行新模型实验。**P31与V50确实呈现不同的来源解释轨迹，但没有建立它们在实际前向计算采用来源上的差异。**两条都在明确分离标签与目标之前算出了正确目标，之后的正常计算也没有显示改用标签17。

新增发现是P69也有明确分离后的错误重述；更接近“实际采用”的证据来自P22/P47：错误绑定确实进入了局部逆向约束计算。但前者发生在明确分离之前，后者始终没有明确分离，都不是“纠正后再次实际误用”。目前未确认满足完整条件的实际错误传播复发案例。

因此，现有证据支持继续研究**来源解释、逆向检查和前向计算之间的失配**，还不足以把“自然纠错留下未修复的来源关系，导致未来再犯”作为已发现的机制。

## 1. 范围与统一标准

数据固定为PR10提交 `c20e0461c7158ec66b1f69abfd8d132cd6b275c8` 的已有导出：pilot和validation-natural两批，24道基础题×两个种子（0、3），共48条`related_noop`。编号沿用PR10。48条最终框内答案均正确。

这里的“自然”指自由生成轨迹；题目已经改写为`sentence_fact_dag`，并使用`single_pass_named_results_v1`提示协议，不能直接代表不受协议约束的一般自然推理。

统一区分三层证据：

1. **说错来源**：直接把标签17称为目标17；与提问、引用旧错误、假设相区分。
2. **错误来源进入局部计算**：例如从错误目标17反推上游12。即使代数正确，其前提仍错；不因最终答对而抹掉这类错误。
3. **错误结果被继续采用**：错误工作值进入后续非假设计算。要支持“纠正后复发”，还须有此前实际误用、中间纠正、此后同来源再采用的完整时序。

明确分离S只根据当时的文字判定，不以未来表现反推。S后提问Q、条件分支H、错误重述W分别记录。H的作用域跨段保持，不能因为下一段省略了“if”就改判为实际采用。17在合法常数、中间结果和其他干扰中也出现，必须按实体追踪。

详细定义见[统一标注标准](related48-annotation-codebook.md)。全部48条见[逐例索引](related48/INDEX.md)，包括证据、完整原文、段落位置和机器可读标注。

## 2. 全队列结果

| 来源解释的可见表现 | 条数 | 说明 |
|---|---:|---|
| 明确分离后又错误重述目标17 | 2 | P31、P69 |
| 明确分离后仍有问题或假设，但未见错误再断言 | 31 | 不能把所有复核都当错误复发 |
| 首次明确分离后未见重新质疑来源身份 | 10 | 包括V50；不全是“先污染再恢复” |
| 始终没有明确分离，冲突解释延续 | 4 | P05、P47、V13、V58 |
| 始终独立命名，没有显式修复事件 | 1 | V51 |

共43条出现明确分离。上述分类是本队列的描述性结果，不是总体发生率；两种子也不是两道独立题。31/10的分界对最早S的句子边界较敏感，不能直接拿“后续持续分离”这个包含未来信息的标签做步前预测。

实际采用层级另行记录：P22/P47有非条件式错误反推；V58的一段反推复核语气不明；另有仅落在假设分支的数值约束证据，例如P24/P66/P69/V21。**没有确认错误结果被后续正常前向链采用的案例，更没有确认严格纠正后复发。**未确认项保存为`null`，不是“已证明没有发生”。

## 3. P31与V50：差别在哪里，不在哪里

以下§编号对应随包发布的完整分段原文。

| 阶段 | [P31](related48/cases/P31.md)：目标14 | [V50](related48/cases/V50.md)：目标4 |
|---|---|---|
| 初始表述 | 把目标写成given 17（§4、8） | 把目标写成17，并反复说题面直接给定（§4–42内多处） |
| 分离之前的计算 | §25、37、40已得到14 | §25、26、30、40已得到4 |
| 明确来源分离 | §57、59开始明确区分；§84尤其清楚地说标签不是目标 | §49命名`S_labels`，§50区分`S_Haddock`，§51承认先前误绑定，§55重建变量表 |
| 此后变化 | §60、66、70、83、117仍有错误题面归引 | 此后未见再质疑两者身份；复核算术时仍明确标签无关 |
| 已写出的正常计算 | §82、95、115、120等仍是`19+(0+18)≡14` | §67、68、77、84等仍得到4 |
| 最终 | 14，最终说明也分清标签 | 4，最终说明不再提标签 |

P31最稳健的回摆证据是**S84→W117**：§84明确说17是标签数、不是Squash Court本身；§117又非条件式地错误声称第一句说Squash Court等于17。后面紧接的“如果是同一数量”是条件复核，但不能把前面的错误归引消掉。它确实是解释回摆，不只是一直没想清楚。

V50表现出更明确的文字层面的变量拆分：从同一个S改成`S_labels`与`S_Haddock`。这是值得跟踪的可见行为，但**尚不能归因于变量改名产生了修复效果**：它在改名之前已经计算出4，没有可观察的错误计算→正确计算转换。

因此，可以说二者的“来源解释保持程度”不同；不能据此说P31实际读了错误笔记、V50实际回到题面，也不能说二者内部来源选择已被识别。正确算式同样可能来自题面、先前正确笔记或重新计算，仅凭这批文本不能区分。

## 4. 新增与边界案例

### P69：第二条解释回摆，不是实际传播复发

[P69](related48/cases/P69.md)的§62已明确说标签与Tiger's Ulna不是同一数量，§116却又错误归引题面目标17。这个**S62→W116**不依赖最早S32的宽松边界。

它确实写出了目标17反推Alula13，甚至进一步反推上游和为1。但是§94、§118、§145分别以替代解释/假设开启分支，后续与正常计算得到的0冲突并被否决。特别是§120的单独`T_Ulna = 17`，受§118假设支配，不能截取成一次新的实际采纳。正常前向结果仍为0。

### P22/P47：不能一概称为“只是想一想”

[P22](related48/cases/P22.md) §9、17把错误目标17与`T_H=5+R_T`合并，写出`R_T=12`，并说“必须是12”。这是错误来源进入了局部反推约束，不只是重复数字。可是这些发生在首次明确分离§19之前；分离后的同类反推§75明确受“if”支配，并与正常值19比较后否决。

[P47](related48/cases/P47.md) §30、31、37等从错误`ZG=17`反推`KH=22`，与正确前向得到的0制造矛盾。随后更深的反推（§49–51、106–114）处于明确假设分支，最终被拒绝。整条没有明确分离事件，所以即使把局部反推看作误用，也不是“纠正之后再犯”。

这两条是现有数据中“错误来源怎样进入验证过程”的较强证据；它们不证明错误约束已替换正常工作值。

### V58：保留不确定，不补写轨迹里没有的操作

[V58](related48/cases/V58.md)先在假设分支中从目标17反推出`WL−BWG=13`。§169决定答0，§170又复核逆元，§173不带if地重述差值13，§174考虑怎样调整。这里可能仍是旧假设复核，也可能是重新采纳约束，文本不足以完全消歧。

因此标为不确定，而不是确证的复发。它始终没有明确来源分离；也**没有实际写出将WL改为12**。不能用我们离线能算出的潜在错误值替代模型真正写过的计算。

## 6. 对研究路线的判断

目前最有根据的命题是：**在这些轨迹中，错误来源解释可以与正确前向推导并存；部分错误解释还进入了逆向一致性检查，但没有证据表明它接管了后续正常计算。**

这比“模型不断纠错又犯错”更准确，也比“只是无害的冗长”更具体。值得保留的候选方向是：前向计算与验证检查是否以不同方式处理来源冲突，以及文字层面的来源分离为什么不总能保持。但这里的“不同过程/机制”仍是假设，不能把文本分段当成已识别的内部模块。

原路线最大的证据缺口不是少找一个显眼句子，而是**缺少错误来源重新被实际消费者使用的机会与证据**。核对任务DAG后，24道题里受相关干扰指向的量全部是最终目标，均无后续消费者节点。这不排除轨迹中的反向检查，但使“给未来留下陷阱”的正向传播假设很难由这批任务充分检验。

因此，当前不宜把这些轨迹直接命名为“自然修复后仍留有错误依赖”的正样本，也不能因为没确认复发就否定这个假设。将来若继续该路线，关键判据应是：有明确纠正前后状态、有同一来源的后续消费、能排除假设分支，并且错误消费产生可预先区分的结果。这里仅列证据门槛，本轮没有执行这些新实验。
