# PR9 小规模完整流程先导实验

目的：先检验真实 Qwen3-8B 的生成、测量、拟合、校准及干预流程，查看探索性信号后再决定扩大。不是正式确认性结果，也不承诺这轮能排除所有 bug。

## 冻结方案

- 来源：上一轮 PR9 的 64 题开发暴露数据，固定 12 个题目族。按身份哈希、难度与已有划分选取；不使用正确率、匹配度或效应选择题目。
- 难度：op5/op10/op15/op21 各 3 题。
- 划分：probe_train 4、dev 2、calibration 1、direction_fit 2、test 3，保持原 split_seed=7319。
- 保留 base/related_noop/neutral_noop、全部前提扫描、来源/数值对照、随机与弱层干预对照、三个特征时机及层 0/12/24/35。
- 参考 seed=[0]，独立噪声 seed=[3]，每个前提一个合法编辑值；max_new=32768，采样参数沿用上一轮。减少重复测量，不用截断制造错误。
- GPU 2、3、6，每卡 batch=2；每次 GPU 子进程开始前要求至少 27,500 MiB 空闲显存。这不是独占预约。
- 554 个请求：reference 36、noise 36、edit 450、source 32。经过原协议与检查点哈希验证复用 36 个参考结果，仍需生成 518 个请求。原始检查点保持不变，迁移来源记录在 checkpoint_reuse.json。
- 先做本轮，不自动恢复 64 题全量运行。运行窗口 12 小时；窗口限制不会把未完成或不可估计写成成功。

## 结果如何判断

1. 实际执行：请求集合完整、没有未处理异常；各阶段输出存在且可验证。已通过的 43 项回归测试不能代替真实模型的完整执行。
2. 测量：查看解析/匹配覆盖、噪声共同支持、未知格子和额外响应；未知不填成负标签。审计字段保持未标注，需独立人工核查。
3. 拟合：报告 dev/test 指标、方向正负样本数及校准状态。dev AUC 不可估计则按原规则停止无法构造的干预；方向缺少两类则 P3 不可估计，不以随机方向替代。
4. 干预：报告实际执行数量、非零 hook 范数及 main/random/weak 控制匹配。只有实际执行并满足原范数标准的配对才进入有效统计；对照不合格不能写成无效应。
5. 扩展：先检查可估计性、覆盖和审计，再看主干预相对对照的方向与区间。只有 3 个测试题目族，偶然改善不能作为科学成功；无信号也可能是样本不足。扩大时重新冻结设计，确认性检验使用独立数据。

## 错误预测的限制

上一轮 64 道 base 原题各跑 3 个 seed，192/192 次最终答案正确，因此 P1 的错误预测缺少真实答错样本。本轮允许单类答案继续测量其他问题，但 P1 仍诚实报告不可估计。答案正确不等于推理没有无关依赖；P2/C2/P3 等检验仍需测量和对照。

若后续要评估错误预测，应独立设计更难的数据，在不按已观察对错挑题的条件下取得两类自然完成结果；截断、解析失败不作为真实推理错误的证据。
