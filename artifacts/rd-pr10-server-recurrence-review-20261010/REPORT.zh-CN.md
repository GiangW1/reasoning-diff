## 2. 判定方法与覆盖边界

本轮恢复并检索筛查了168条全文，另对24条候选/对照做了重点上下文复核，其中20条是related_noop。优先复核交接指定的P05、P22、V24、V17、P24、V13、E24，再检查新恢复文本里的来源冲突、明确分离、逆向约束与模等价反例。该选择是有目的的候选复核，**不是168条穷尽逐步语义标注，不提供总体复发率或发生率置信区间**。

这是当前Codex助手基于完整原文对原审计结论的独立复核，不是第二位人类标注者，也不是独立金标准。旧parser的correct与FTF只用来定位；模型自称wrong/mistake也不直接视作真值。

严格判断要求顺序完整：同一可识别来源被实际错误采用并影响计算；模型自行改正相关数值；之后错误再次进入实际执行的计算；实体、绑定或操作数能证明同源。另记是否明确纠正来源解释。错误重述、对旧步的引用、If/Suppose/Alternatively中的候选计算与矛盾排除分别记录。不明确的首次实际采用或后续实际使用保持null，不升级成正例。

本轮确认的“数值纠正后同源实际计算复发”和“来源解释明确纠正后同源实际计算复发”均为0，**这里的0只指24条重点复核中未确认正例**。P47、V58仍有约束语气/当前工作状态方面的不确定性，不能据此宣称一般不存在该现象。

## 4. 确定性算术与任务结构

[task-sensitivity.json](task-sensitivity.json) 使用标准库AST独立求值保存的任务图，没有调用模型，也没有调用原包装脚本的求值实现。24个PR9基础任务的保存节点值与答案全部重算一致。对174个非目标节点分别遍历全部23个余数；所有174个节点均有通向目标的图上路径，但其中15个节点、分布在6道题内，最终答案对其全部余数恒定。图上存在依赖不等于最终数值敏感。

**V17是真实算术传播后恢复的对照。** 模型把 `(18+12)+6` 算成42，得到 `Aquarium's Frilled Lizard=19`，正确应为13；错误改变8个后续非目标量。后来自行指出18+12应为30，改用13并重算。然而该节点取任何余数，最终答案都是7：

`225*(12*x-6) + 2*x + 12*x = 2714*x - 1350 ≡ 7 (mod 23)`。

因此，终点7不是纠正带来的准确率提升，不能把错误路径答对当作已经恢复。纠正前后的局部量确实不同，恢复证据来自实际重算过程。完整错误链和纠正链见 [V17](evidence/V17.md)。

本批相关干扰模仿的是最终目标，而24个基础任务的目标在保存图中均没有下游消费者。这限制了通过后续新用途观察旧值重新进入计算的机会。文本仍可能重算或逆推，但不能假装图上原本就有目标的后续消费步骤。

## 5. 研究路线判断

现有证据支持三层观察：相关干扰可能诱发错误来源解释；部分轨迹能明确分离来源，部分持续冲突或反复重述；真实算术错误可以传播并自行纠正，同时最终准确率可能被抵消掩蔽。现有文本没有确认严格的纠正后同源实际计算复发，不能据此宣称发现旧内部绑定残留机制。

因此，**现阶段不足以启动以该复发机制为前提的探针、激活或干预正式大实验**。这不是对机制一般不存在的判断，而是当前任务结构、提示和候选复核能支持的证据边界。即使未来找到完整文本复发，文本也无法区分旧绑定残留和后续独立重读误解。

若下一轮仍以同源实际复发为目标，优先改变可观测性：让会混淆的中间量有多个后续真实用途；预先通过确定性重算筛出局部与终点数值可区分、不会抵消的任务；提前定义实际采用、来源纠正、假设排除的标注规则，并先取得有完整四阶段证据的自然案例，再考虑内部机制实验。保留每题一条原始推理、每个编辑/噪声对照只生成一次的预算口径。这些仅为下一轮建议，本轮没有生成新任务或输出，按交接要求交由用户决定后续方向。
