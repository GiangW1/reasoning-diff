# 自然轨迹匹配：损失定位与解析修复

代码版本：`4a96263`。本轮仅复用已保存的 48 条真实 pilot 轨迹及旧 335 条轨迹做 CPU 重算，没有新增模型生成。原始生成仍来自 `d02a40c`，不是用最新代码重新生成的实验。

## 主要瓶颈

当前系统把自然文本中的每次数值陈述都作为一个待配对事件。两条独立生成轨迹的复核次数、原始值/取模值的打印方式、计算与文字确认方式不同，因此不能假设每个陈述都有唯一对应项。提示中的“不重复检查”也没有被模型稳定遵守。

最新 pilot 的 483 个非任务祖先事件×前提单元中，234 个可配对。249 个缺失单元的算法损失分类如下；这是对**当前解析结果**的诊断，不是人工标注的真实缺失原因：

| 损失类别 | 单元数 |
| --- | ---: |
| 有兼容候选，但不在全局最优顺序/上下文路径中 | 139 |
| 重复步骤仍有歧义 | 62 |
| 有同实体，但没有同阶段候选 | 38 |
| 没有同实体候选 | 7 |
| 表达式不兼容 | 3 |

前两类占缺失单元的 80.72%。不能把它们全部解释为程序漏配：数量不对称也会落入这两类。0008 题 seed 0 当前有 46 个计算/确认事件，两条无关编辑轨迹分别有 19、22 个。因此在这些解析事件上，即使忽略表达式、顺序和歧义，一对一配对上限也只有 `(19+22)/(46*2)=44.57%`。这个上限不适用于尚未解析的原文；它证明的是仅更换当前事件集上的匹配算法不足以通过该题 50% 检查。

此前的修复主要按单个漏解析案例推进，没有先分清解析召回、对应关系准确性和轨迹结构差异。DAG 变量覆盖 100% 只说明每个变量至少被识别一次，不能说明每个步骤均被正确抽取。测试通过和某个总体匹配率上升都不足以验收测量。

## 本轮代码修复

- 修复数字后的普通逗号被数值正则吞掉，导致 `X is 16, ...` 漏解析的问题，保留合法千分位。
- 支持明确指向已知来源的文字赋值，例如 `X equals Y, which is 3`；未知来源不猜测。
- 支持命名算式后紧接的匿名取模，如 `X = 15 + 10 = 25. 25 mod 23 = 2`。原始值与余数作为两个阶段保留，不删除原始值以缩小分母。
- 支持公式句后紧接完整数字代入；用表达式结构检查拒绝把局部乘积结果绑定给整个求和变量。不开启跨行或跨话题搜索，不从任务 DAG 计算缺失答案。
- 排除 `A × B = ...` 中被误当成赋值目标的操作数，以及显式 if 条件句中并未实际提交的值。
- 为未匹配事件保存候选数量、兼容候选、最优路径候选与损失原因；pilot 和 CPU pilot 重算自动生成 `alignment_audit`。审计使用完整生产序列（包括复述锚点），逐轨迹核对分母、匹配数和共同噪声支持数，不能用不同筛选口径生成好看的诊断。

自然规则版本为 `printed_expression_views_forced_sequence_v6`。没有放宽 50% 门槛、引入值相似度配对、把缺失写成负标签、复用 donor 伪造一对多对应，或将独立受控条件当作自然条件通过。

## 复测结果

| 同一批 48 条真实轨迹 | 上版 v5 | 本版 v6 |
| --- | ---: | ---: |
| 非任务祖先候选单元 | 433 | 483 |
| 已匹配单元 | 226 | 234 |
| 匹配覆盖率 | 52.19% | 48.45% |
| 共同噪声支持单元 | 183 | 200 |
| 共同噪声覆盖率 | 42.26% | 41.41% |
| 有完整匹配噪声支持的 ρ | 1/8 | 2/8 |

识别出的真实陈述增加后，分母也增加，所以比例没有随匹配数量一起上升。这不是新一轮 GPU 结果，也不能据此宣称自然匹配已通过。

旧 335 条轨迹重算：24 条 base 的匹配数 `4212/9064=46.47%`，共同噪声支持 `3374/9064=37.22%`，完整 ρ 仍为 `0/24`。与上版比较同样需要考虑解析分母变化。

两批数据的测量检查均未全部通过。主报告继续保留失败状态；不启动正式扫描、探针、干预或 P1 科学结论。48 条 pilot 均自然完成，base 24/24 答对；该小样本本身也缺少 P1 的错误类别。

## 剩余验收工作

下一步必须针对完整原文标注计算阶段、复述/复核和替代推导，把真正没有对应步骤与解析器遗漏分开验证。现有词汇上下文唯一性不是语义准确率证明；本轮针对已发现错误的检查也不是独立、盲测的总体 precision/recall。若原文确实出现不对称的推导，原来的逐次陈述一对一估计量必须把这些单元记作结构变化，不能靠程序强配恢复。

在这项验证完成前，不能保证修改 matcher 或再加一句 prompt 就能让新自然轨迹通过，也不值得重复一整天的实验。下一次模型生成应仍限定为事先登记、限时的小规模验收，并明确验收的是哪一种自然事件单位；本轮没有执行或安排这次生成。
