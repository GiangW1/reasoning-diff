## 本次变动

`registered_quantity_constrained_v2` 保持单一自回归序列、一个 RNG 和一套 KV 缓存。节点标签和结构由解码器确定，文字与整数由模型采样，不读取标准答案或节点真值。

v1 屏蔽了模型关闭当前步骤的 token，导致继续重复文字。v2 将关闭标签、thinking 结束及 EOS 的 logits 用 logsumexp 合并到当前数量的提交动作，再按登记温度/top-k/top-p 采样。属于显式改变解码分布的受控条件，不能算作无干预的自然推理。词表大小只在初始化时查询一次，避免每 token 重复触发约 30ms 的查询。

每节点文字仍最多 512 token；达到上限要求提交模型采样整数，并记录触发次数。整数允许符号和最多 12 位数字，不限于模数范围；总 token 预算截断仍失败，不补生成或补闭合标签。格式覆盖是构造性质，不能当作科学成功；要看语义使用、正确率、单次噪声敏感性和后续指标。
